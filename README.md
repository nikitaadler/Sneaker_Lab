Данный сайт я создал в рамках учебной практики. 
Sneaker Lab - веб-магазин кружек с возможностью зарегистрироваться, добавить товар в корзину и совершить покупку.
Технологии, которые я использовал: html, css, js и php.
C помощью php я сделал возможность зарегистрироваться и оформить покупку.
С помощью js я сделал фильтрацию товаров по нескольким признакам(оценка товара пользователями, цвет товара, цена товара), добавление товаров в корзину, слайдер с акциями.
